# Primitive DB

Простая программа для управления таблицами и их метаданными.

## Управление таблицами

Программа позволяет создавать и удалять таблицы, а также получать справочную информацию.

### Создание таблицы

Команда:

```text
create_table <имя_таблицы> <столбец>:<тип> ...
```

Пример:

```text
create_table users name:str age:int
```

В таблицу автоматически добавляется столбец `ID:int`.

Поддерживаются следующие типы данных:

- `int` — целое число
- `str` — строка
- `bool` — логическое значение

### Удаление таблицы

Команда:

```text
drop_table <имя_таблицы>
```

Пример:

```text
drop_table users
```

Если таблицы с указанным именем не существует, программа выводит ошибку.

### Справка

Команда:

```text
help
```

Выводит список доступных команд.

### Выход

Команда:

```text
exit
```

Завершает работу программы.

## Пример использования

Запуск программы:

```text
project
```

Создание таблицы:

```text
create_table users name:str age:int
```

Результат:

```text
Таблица "users" создана.
```

Удаление таблицы:

```text
drop_table users
```

Результат:

```text
Таблица "users" удалена.
```
